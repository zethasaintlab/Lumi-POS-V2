# Sub-proyek 2 · PR 2C — fungsi toolbar baru: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Nama skill tanpa awalan `superpowers:` di repo ini.

**Goal:** Lima tombol toolbar sisanya bekerja — Pajak (pilihan kanal), Catatan, Pelanggan, No. Meja, Pesanan tahan — dan G-TOOLBAR menuntut kedelapan label mockup.

**Architecture:** Kanal disimpan di keranjang dan mengalir ke `hitungKeranjang`/`simpanPenjualan`/`POST /orders` yang sudah menerimanya. Label pesanan memakai `check.label` yang sudah ada (`[BAWAAN P5]`); catatan memakai kolom baru `order.note` (`[BAWAAN P6]`, satu migrasi). Pesanan tahan adalah tabel murni lokal `keranjang_tahan`.

**Tech Stack:** SQLite lokal + PowerSync raw table, PostgreSQL (migrasi expand + `lock_timeout`), Fastify, React 19, `node:test`, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-28-kasir-design.md` § 4 (tabel baris 3–6, 8; "Pajak sebagai pilihan kanal"; "Pesanan tahan — batas yang dinyatakan"; "Aturan tombol"), § 11 G-KANAL, G-TAHAN, G-TOOLBAR, § 14 R4/R7/R8.

**Indeks (wajib dibaca controller):** `docs/superpowers/plans/2026-09-28-kasir.md`.

**Urutan rilis (R8):** server lebih dulu (Task 11 menambah field opsional + kolom), klien sesudahnya.
